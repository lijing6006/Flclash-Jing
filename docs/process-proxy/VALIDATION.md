## Windows 验收（须受信任Windows测试机，显式操作）

1. 安全模式确认启动按钮禁用。首页停止/core断开/监听暂停/配置未应用/direct模式/TUN或系统代理启用时，启动拒绝且不创建目标。
2. 用非默认mixed端口、独立SOCKS端口、HTTP回退、带认证分别验证；修改端口并取消/失败应用时不能连到错误监听。
3. 选择自己拥有的测试应用，观察本地测试服务的目标与选定节点；验证子进程、双击重复启动、窗口导航与核心重启。
4. 检查同名程序的PID/路径；已有浏览器保持原状，明确新实例/复用行为，不自动结束工作。
5. 逐项验证域名、IPv4/CIDR、IPv6字面量、私网及公司split-DNS。不要把域名优先限制误判为完整IP策略。
6. 高级页首次状态不捕获、不解密、不录制。先只查询CA，确认证书存储没有变化；任何信任操作必须由操作者单独确认。
7. 自己的测试流量进行HTTPS/QUIC监视、录制与离线回放，验证Start/Stop/Cancel、配额、错误与丢帧状态；退出后无新增采集。
8. 验证错误不会显示密码、token、原始后端异常；检查配置/录制目录权限与清理策略。
9. 检查 x64/x86/ARM64兼容边界、低权限/提权拒绝、缺失/错误版本DLL、AppLocker等策略拒绝。不要关闭防护绕过。
