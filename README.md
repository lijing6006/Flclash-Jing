## English

A project for researching, integrating, and validating FlClash customization and per-process proxy functionality.

This commit initializes the public repository and verifies the publication path only. The complete source, installable builds, and final validation results have not yet been published here. This is not a completed or production-ready release.

Subsequent commits will preserve applicable upstream licenses and attribution, and document changes, test results, and remaining validation limits. Personal subscriptions, proxy credentials, secrets, and other private configuration will not be uploaded.
